# 航母調度指揮 · Carrier Command Deck Ops

管理一艘航母的甲板作業：出庫、整備、滑行、彈射、降落與回收。支援日夜任務、戰損與雙人房間對戰。

Manage carrier deck operations: launch, recover, refuel, rearm and repair your aircraft through day and night missions, with online two-player matches.
