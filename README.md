# 航母調度指揮 · Carrier Command Deck Ops

管理一艘航母的甲板作業：出庫、整備、滑行、彈射、降落與回收。支援日夜任務、戰損與雙人房間對戰。

Manage carrier deck operations: launch, recover, refuel, rearm and repair your aircraft through day and night missions, with online two-player matches.

1. 系統需求：Android 8.0 以上，建議橫向遊玩。 / Android 8.0 or later; landscape recommended.
2. 發布後，從 Releases 下載 `.apk`，開啟檔案安裝。系統可能要求允許目前使用的瀏覽器或檔案管理器安裝未知應用程式。 / After publication, download and open the APK; Android may request permission to install from that app.
3. 已安裝相容舊版時請直接覆蓋更新。不要為更新而先解除安裝，以免遺失本機進度。 / Update over a compatible existing installation; uninstalling can erase local progress.
